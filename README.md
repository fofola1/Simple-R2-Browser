Simple R2 browser

A very simple browser for Cloudflare R2. It allows you to view and download files from your R2 buckets. No design, no frills, just a simple browser. No authentication is required, but you will need to provide your R2 bucket name and region in the config file.

It does not list root of the bucket, but you can navigate to any folder by typing the path in the address bar. This is not a bug, but a feature for my own use case! If the folder above is not a root, you can still navigate to it by either typing the path in the address bar or by simple html navigation.
